# Proposar pàgines per a l'assistent

A la pestanya **Pàgines** tries el lloc i veus totes les pàgines rastrejades. Marca **Per a l'assistent** en les que haurien d'alimentar l'assistent. Queda guardat qui la va proposar i quan.

**Proposar no publica res.** Qui administra l'assistent veu les propostes a **Publicació** i decideix què hi entra. Amb **Només les proposades** veus les que ja has marcat. Abans de decidir pots llegir-ne el text amb **Veure text guardat**.

## Pàgines que no es poden proposar

Les **pàgines de navegació** —índexs amb enllaços i sense text propi— tenen la casella desactivada, amb l'avís «Pàgina de navegació: no té res a citar». A l'assistent només li serveix el contingut; un índex no respon cap pregunta.

Si una pàgina de navegació ja estava proposada d'abans, la marca es pot llevar.

## Auditoria

La pestanya **Auditoria** mostra l'informe de qualitat del lloc: un resum de les troballes per tipus i gravetat, amb una recomanació per a cada tipus. Serveix per a veure d'una ullada com està l'apartat, i es pot descarregar en Word, o en PDF si el servidor ho permet.
