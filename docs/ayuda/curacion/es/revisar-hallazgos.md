# Revisar los hallazgos

Es la parte principal de la curación. En **Hallazgos** eliges el sitio y aparece la lista de problemas detectados, cada uno con la página afectada y la columna **Por qué**, que da el motivo con sus cifras: la fecha y el criterio de una página desactualizada, los tokens de una escasa, el parecido de una duplicada.

## Decidir sobre cada hallazgo

- **Descartar**: es una falsa alarma y la página está bien. Es lo que hay que hacer cuando la página es correcta.
- **Confirmar**: el problema es real y hay que arreglarlo en el portal o retirar el documento.
- **Resolver**: aparece después de confirmar. Se marca cuando ya se ha arreglado en el portal.

Para decidir, abre **Ver texto guardado**: es exactamente el texto que iría al asistente, sin el menú ni la plantilla del portal. En una duplicada se pueden leer las dos páginas.

Lo que marcas se guarda para toda la organización, con quién lo revisó y cuándo, y se mantiene aunque el sitio se vuelva a rastrear: solo aparecen como nuevos los hallazgos realmente nuevos. El filtro **Pendientes** oculta lo ya revisado; para verlo todo, elige «Todos los estados».

## Los tipos de hallazgo

- **Duplicada**: dos páginas dicen esencialmente lo mismo. Mira si las dos tienen que convivir o si sobra una.
- **Obsoleta**: hay una versión más nueva del mismo documento y la vieja sigue publicada.
- **Desactualizada**: la página tiene una fecha anterior al criterio de antigüedad del sitio.
- **Escasa**: la página tiene tan poco texto propio que no aporta nada.
- **Navegación**: la página es un índice. Tiene enlaces y casi ningún texto propio, así que no hay nada que citar. **No es un defecto del portal**: normalmente se descarta. Una página de navegación no se puede proponer para el asistente.
- **Error de crawl**: un enlace del apartado lleva a una página que ya no existe o que el servidor no sirve.
- **Serie por años**: varias versiones por año del mismo recurso.

## Huecos de corpus

La parte de **Huecos de corpus** de debajo, con un selector de chatbot, es para cuando el asistente ya existe: agrupa preguntas que no supo responder, que suelen apuntar a un documento que falta.
