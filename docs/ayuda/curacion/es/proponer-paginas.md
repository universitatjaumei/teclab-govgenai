# Proponer páginas para el asistente

En la pestaña **Páginas** eliges el sitio y ves todas las páginas rastreadas. Marca **Para el asistente** en las que deberían alimentar el asistente. Queda guardado quién la propuso y cuándo.

**Proponer no publica nada.** Quien administra el asistente ve las propuestas en **Publicación** y decide qué entra. Con **Solo las propuestas** ves las que ya has marcado. Antes de decidir puedes leer el texto con **Ver texto guardado**.

## Páginas que no se pueden proponer

Las **páginas de navegación** —índices con enlaces y sin texto propio— tienen la casilla desactivada, con el aviso «Página de navegación: no tiene nada que citar». Al asistente solo le sirve el contenido; un índice no responde ninguna pregunta.

Si una página de navegación ya estaba propuesta de antes, la marca se puede quitar.

## Auditoría

La pestaña **Auditoría** muestra el informe de calidad del sitio: un resumen de los hallazgos por tipo y gravedad, con una recomendación para cada tipo. Sirve para ver de un vistazo cómo está el apartado, y se puede descargar en Word, o en PDF si el servidor lo permite.
