# Crear un informe i carregar les dades

Un informe es fa sempre a partir d'una **plantilla**, que en fixa l'estructura: quines taules porta i quins apartats valora la IA. Les taules les copia la plataforma tal com vénen en el fitxer de dades; **el model no escriu ni canvia cap xifra**. El que proposa la IA és la valoració de cada taula, i cap valoració arriba a l'informe sense que una persona l'aprove.

## Començar un informe nou

1. Entra a **Informes**. S'obri directament la pestanya **Nou informe**. Les pestanyes «Plantilles» i «Revisió de scripts» són per a qui administra.
2. Tria la plantilla a la llista i prem **Crea l'informe**.
3. Si no trobes la plantilla que necessites, demana-la a qui administra la plataforma: les plantilles les crea i les publica l'administració.

## Pujar les dades de partida

S'obri l'espai de treball de l'informe. A **Dades de partida**:

1. Arrossega el fitxer de dades al requadre, o prem-lo per a triar-lo. Davall s'indica quins formats accepta la plantilla.
2. Ompli els camps que la plantilla demana a banda, si n'hi ha: són les dades que no estan al fitxer.
3. Prem **Continuar**.

Si tornes a aquesta pantalla més tard, el fitxer que ja vas pujar apareix com a «ja pujat»: es reutilitza si no en tries un altre.

## El mode d'anonimització

Més avall hi ha el **Mode d'anonimització**. Substitueix les dades personals per dades sintètiques abans d'enviar el text al model, i quan torna la resposta hi torna a posar les reals. Les opcions són «Desactivat», «Només detectar», «Reemplaçar (Faker)» i «Reemplaçar + LOPDGDD», que a més emmascara el DNI, el NIE i el passaport. El mode no es pot canviar mentre l'informe s'està generant.

## Esperar la generació

La pantalla s'actualitza sola mentre extrau les taules i redacta les valoracions; sol tardar uns minuts. La barra de dalt indica l'estat: «Preparant», «Extraient dades», «En redacció» i, quan ja es pot revisar, **«En revisió»**. El pas següent és revisar les valoracions.
